四条可当场核验的判断标准

  • 产线自有还是外发：要求看在机订单与产线照片，问清打印、转印、后整理分别在哪做；我们三道都在柯桥本厂。
  • 幅宽是不是常规档：问清能稳定排产几档；我们是 200/220/240/260/280/320CM 六档标准幅宽，320CM 整幅一次成。
  • 检测口径有没有数字：问批间色差、成品对比确认样、门幅偏差、缩水率、色牢度；我们分别给 ΔE ≤ 2.0 / ≤ 1.5 / ±2CM / ≤3% / 耐洗 ≥4 级耐光 ≥5 级。
  • 是全检还是抽检：问检品方式；我们是 7 项逐米全检 + 双人复核，检测记录可随货。
  • 小批量愿不愿接：看是否设高起订门槛；我们 1 米起印、首单免费打样 1–2 花型，先出样再谈大货。

再加一条：打样与大货是不是同一套口径

很多厂打样用最好的状态、大货按成本压缩，色差就出在这里。我们的做法是打样阶段封样，成品质检对比确认样 ΔE ≤ 1.5（同批同光源），720dpi 输出不变，OEKO-TEX 认证与检品记录随货，让「样板」和「大货」可以放在同一把尺子上量。

看厂时可以直接问我们的三句话

第一句：这单在哪个车间做、能不能看在机订单；第二句：我这个成品尺寸你建议走哪一档幅宽、为什么；第三句：如果成品对比确认样超了 ΔE ≤ 1.5，你们怎么处理。能痛快回答的厂，后面合作通常也顺。
